Token Radar (model radar-2): ranks pre-token protocols by implied launch value using only the snapshot's own figures — each category's median live-token market-cap/TVL multiple, a 7-day momentum factor, a maturity factor and a multi-chain reach factor — with a full board, an early radar below the watchlist floor, per-protocol farm plans with costs and times, and a searchable, filterable dashboard.

## Run it

```sh
node main.ts --input <snapshot.json>
```
